# 03 - Password Generator 

Python CLI application to generate secure passwords with customizable options such as uppercase letters, numbers, and symbols.

## Features

- Custom password length
- Optional uppercase letters
- Optional numbers
- Optional symbols
- Input validation
- Portfolio link at the end

## Technologies

- Python 3
